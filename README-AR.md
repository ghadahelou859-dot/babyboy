# كرت استقبال يس — نسخة GitHub Pages

1. أنشئي مستودعًا جديدًا في GitHub.
2. ارفعي جميع الملفات والمجلدات الموجودة هنا كما هي، مع إبقاء مجلد `assets`.
3. افتحي: **Settings → Pages**.
4. اختاري **Deploy from a branch**، ثم الفرع **main** والمجلد **/(root)**.
5. اضغطي **Save** وانتظري ظهور رابط الكرت.

مهم: لا تغيّري أسماء الملفات ولا تنقلي الملفات خارج مجلداتها، لأن الصور والفيديوهات والصوت مرتبطة بمسارات نسبية مناسبة لـGitHub Pages.
